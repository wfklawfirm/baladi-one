# تدقيق الدورة المالية

| المرحلة المطلوبة | الموجود | الحالة |
|---|---|---|
| توفر الاعتماد | بنود موازنة، اعتماد حالي، متاح = اعتماد − التزامات | Partially Implemented |
| عقد النفقة | `finance_commit` يمنع تجاوز المتاح | Partially Implemented (بلا مرجع مختص ومستند قانوني) |
| تصفية النفقة | — | Not Implemented |
| أمر الصرف | — | Not Implemented |
| الدفع | `finance_pay` (جزئي/متعدد ممكن؛ دون التزام مسموح مع تحذير فقط) | Partially Implemented — **الدفع بلا التزام غير ممنوع** |
| المطابقة (صندوق/مصارف) | — | Not Implemented |
| تعديل الاعتماد | بقرار معتمد + تصديق قبل التطبيق | Implemented — Pending Legal Review (نقل/تكميلي/استثنائي غير مميَّز) |
| إقفال السنة وقطع الحساب | — | Not Implemented |
| فصل الأدوار المالية | دور رئيس/مدير فقط | Not Implemented |
| سجلات مالية قانونية | جزء من جداول | Partially Implemented |
| ترقيم الإيصالات | `receipt_no` غير فريد | Not Implemented |
| منع تكرار التحصيل | يمنع تجاوز المتبقي من المستحق | Partially Implemented |
| عملة الموازنة | تنبيه بند الدولار فقط | Partially Implemented |

الأساس القانوني (5595/1982 وقانون المحاسبة العمومية والنظام المنطبق على خريبة الجندي) لم يُراجَع: لا قاعدة بالمنع تُضاف قبل ذلك.
