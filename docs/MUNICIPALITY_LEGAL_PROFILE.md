# الملف القانوني لبلدية خريبة الجندي
جميع الحقول التالية **تتطلب تحققًا قانونيًا** ولا مستندات مرفقة تثبتها في النظام، فلا تُفعَّل قواعد مالية ملزمة تعتمد عليها.

| الحقل | الحالة |
|---|---|
| القضاء والمحافظة | يتطلب تحققًا قانونيًا (يُقدَّر: عكار، لم يُثبَّت بمستند) |
| عدد أعضاء المجلس الحالي | غير مسجَّل؛ يُدخَل في كل جلسة يدويًا |
| سلطة الرقابة (قائمقام/محافظ) | يتطلب تحققًا قانونيًا |
| النظام المحاسبي (5595/1982 أم 14969/1963) | يتطلب تحققًا قانونيًا |
| الخضوع لديوان المحاسبة ونطاق الرقابة | يتطلب تحققًا قانونيًا |
| النظام المالي الخاص/المسؤولون الماليون/التفويضات | غير مسجَّلة |
| الأنظمة الداخلية | غير محمَّلة |

المطلوب من البلدية: قرار تشكيل المجلس الحالي، قرارات التكليف والتفويض، مستند يثبت النظام المحاسبي المطبَّق، المراسلات مع سلطة الرقابة وديوان المحاسبة، الأنظمة الداخلية.
